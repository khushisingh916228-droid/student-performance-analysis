# 📊 Student Performance Analysis

A data analysis project using **Python, Pandas, NumPy, and Matplotlib** to analyze student performance and visualize key insights.

This project was completed as part of my Data Science Internship at **Maincrafts Technology**.

---

## 🎯 Objective

To analyze a student performance dataset and answer key questions such as:
- What is the average final grade among students?
- How does study time correlate with final grades?
- Is there a performance difference between male and female students?

---

## 🛠️ Tech Stack

- **Python** — core programming language
- **Pandas** — data cleaning, wrangling, and analysis
- **NumPy** — numerical computations
- **Matplotlib & Seaborn** — data visualization
- **Jupyter Notebook** — development environment

## 🔍 Key Steps

1. **Data Loading** — loaded `student-mat.csv` (395 rows, 33 columns)
2. **Data Cleaning** — checked for missing values and duplicates (dataset was already clean)
3. **Statistical Analysis** — computed average grades, correlations, and group comparisons
4. **Visualization** — histogram, scatter plot, and bar chart to reveal trends

---

## 📈 Key Insights

- Average final grade (G3) is **10.42**
- **40 students (10.13%)** scored above 15 — strong performers
- Study time and final grade show a **weak positive correlation (0.098)** — more study helps, but isn't the sole factor
- **Male students (10.91)** performed slightly better on average than **female students (9.97)**
