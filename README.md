# 📊 Student Performance Analysis

A data analysis project built using **Python, Pandas, NumPy, and Matplotlib** to explore student performance data, uncover key trends, and visualize actionable insights.

This project was completed as part of my Data Science Internship at **Maincrafts Technology**.

---

## 🎯 Objective

To analyze a student performance dataset and answer key questions such as:
- What factors correlate most strongly with student scores?
- How do variables like study time, attendance, or parental background influence performance?
- What patterns emerge across subjects and student groups?

---

## 🛠️ Tech Stack

- **Python** — core programming language
- **Pandas** — data cleaning, wrangling, and analysis
- **NumPy** — numerical computations
- **Matplotlib** — data visualization
- **Jupyter Notebook (Google Colab)** — development environment
